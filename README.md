# Контрольные вопросы

## 1. Чем `List<T>` отличается от массива?

- List: в нём можно менять кол-во элементов

## 2. Какой способ доступа используется для элемента `List<T>` и что означает `Count`?

- Для него по индексу. Возвращает кол-во элементов

## 3. Для какой задачи удобен `Dictionary<TKey,TValue>`?

- Когда требуется, допустим тел. и к нему привязано имя

## 4. Чем `TryGetValue` полезнее прямого обращения `dictionary[key]` при поиске?

- Он обходить аварийное завершение команды, если будет ошибка

## 5. Для чего нужен `HashSet<T>` и почему в нём не появляются дубликаты?

- Он нужен для того, если нам не надо иметь повторки

## 6. Почему для списка товаров, телефонного справочника и набора уникальных тегов подходят разные коллекции?

- Они по разному удобны в этих ситуациях

## 7. Представьте задачу «имя студента → его средний балл». Почему здесь удобнее `Dictionary`, чем `List`?

- Нам легче будет обратиться к ключу(-имя) после чего получить значение(-ср. балл). И также в List надо тогда создать два списка, что требует больше памяти
